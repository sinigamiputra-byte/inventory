# SI Inventory Barang

Sistem Informasi Inventory Barang berbasis PHP native dan MySQL.
Proyek praktikum mata kuliah **Praktek Pemrograman WEB II** — Politeknik Bisnis Indonesia.

## Fitur (Pertemuan 10)

- Koneksi database dengan PDO
- Dashboard ringkasan stok dan daftar stok menipis
- Daftar seluruh data barang dari database
- Daftar kategori beserta jumlah barang

## Teknologi

- PHP 8 (XAMPP)
- MySQL / MariaDB
- HTML dan CSS

## Cara Menjalankan

1. Salin folder `inventory` ke `C:\xampp\htdocs\`
2. Jalankan **Apache** dan **MySQL** di XAMPP Control Panel
3. Buka `http://localhost/phpmyadmin`, lalu impor file `database/db_inventorybrg.sql`
4. Buka `http://localhost/inventory`
